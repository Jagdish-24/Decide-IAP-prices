# Google Play Developer API • Complete Synchronization & Verification Guide

This guide provides end-to-end instructions for automating in-app purchase (IAP) pricing updates in the Google Play Console using the official **Google Play Android Developer API (v3)** and localized data generated by the **PlayPrice Engine**.

---

## 1. Executive Summary & Verification

### Country Roster Verification
* **Google Play Distribution Locations:** Google Play distributes apps to **174 distinct sovereign nations/regions**, plus 2 regional fallback groupings ("New countries/regions (USD)" and "New countries/regions (EUR)").
* **PlayPrice Engine Database:** [countries_data.js](file:///j:/git/git_projects/Decide%20IAP%20price/countries_data.js) contains all **176 locations**:
  - **174 sovereign country locations** verified with official ISO 3166-1 alpha-2 country codes (`US`, `IN`, `GB`, `DE`, `BR`, `JP`, `KR`, `DZ`, `AL`, etc.).
  - **2 global fallback pools** (`GLOBAL_USD`, `GLOBAL_EUR`).
* **API Compatibility:** The Google Play Developer API strictly expects 2-letter ISO 3166-1 alpha-2 country keys. Our automation script automatically validates every record against Google's official 174-country registry.

---

### Paid App Price vs. In-App Product (IAP) Pricing

| Aspect | Paid App Download Price | In-App Product (IAP) / Managed Products |
| :--- | :--- | :--- |
| **API Support** | ❌ **No Public API** | ✅ **100% Supported via `inappproducts` & `monetization` APIs** |
| **How to Update** | Manual entry in Play Console under **Monetize > Products > App pricing** | Automated via `sync_prices_to_play_console.py` or manually in Console |
| **PlayPrice Support** | **1-Click Copy** buttons + **Copy Play Store Format** | Direct **CSV / JSON batch export** + automated API script |
| **Important Rule** | A **Free** app can **never** be converted to **Paid**. (Paid apps can be changed to Free permanently). | IAP prices can be updated, raised, lowered, or discounted anytime without app re-review. |

## 2. One-Time Setup: Google Cloud & Play Console Credentials

> [!NOTE]
> This setup is **100% free**. No credit card or Google Cloud billing account is required to use the Google Play Android Developer API.

### Step 1: Enable API & Create Service Account in Google Cloud
1. Go to the [Google Cloud Console](https://console.cloud.google.com/).
2. Select or create a project (e.g., `Play-Store-Automation`).
3. In the top search bar, search for **Google Play Android Developer API** and click **Enable**.
4. In the left navigation, navigate to **IAM & Admin** $\rightarrow$ **Service Accounts**.
5. Click **+ Create Service Account**:
   - **Service account name:** `play-pricing-updater`
   - **Service account ID:** `play-pricing-updater` (auto-filled)
   - Click **Create and Continue**, then click **Done**.
6. In the Service Accounts list, click on the newly created service account email.
7. Go to the **Keys** tab $\rightarrow$ click **Add Key** $\rightarrow$ **Create new key**.
8. Choose **JSON** and click **Create**.
9. A `.json` private key file (e.g., `service-account.json`) will be downloaded to your computer. Move this file to your project directory.

---

### Step 2: Grant Permissions in Google Play Console (Current UI)
1. Open the [Google Play Console](https://play.google.com/console).
2. In your developer account dashboard, click **Users and permissions** (found in the left sidebar under *Manage account* or as a card).
3. Click the **Invite new users** button at the top right.
4. In the **Email address** field, paste your **Service Account email address** (e.g. `play-pricing-updater@your-project-id.iam.gserviceaccount.com`).
5. Leave **Set access expiry date** unchecked (service accounts used for API automation should not expire).
6. Under permissions, select **Account permissions** (or use **App permissions** if you want to restrict access to a single specific app):
   - Under **App access**:
     - ✅ **View app information and download bulk reports (read only)** *(Note: "View app quality information" will be selected automatically)*
   - Under **Store presence**:
     - ✅ **Manage store presence** *(This explicitly grants permissions to: "edit pricing; manage in-app products; edit store listing...")*
7. Click **Invite user** at the bottom right.

*(Note: Service accounts are activated immediately upon clicking Invite—no email verification or confirmation link is needed).*

## 3. How Google Play Developer API Handles Pricing

Google Play represents all localized prices as an object of ISO country keys with values in **micros**:
$$\text{priceMicros} = \text{Price} \times 1,000,000$$

For example:
```json
{
  "packageName": "com.mygame.shop",
  "sku": "com.mygame.shop.gold-3",
  "defaultPrice": {
    "currency": "USD",
    "priceMicros": "1490000"
  },
  "prices": {
    "US": { "currency": "USD", "priceMicros": "1490000" },
    "IN": { "currency": "INR", "priceMicros": "39000000" },
    "DZ": { "currency": "DZD", "priceMicros": "64580000" },
    "AL": { "currency": "USD", "priceMicros": "490000" },
    "BR": { "currency": "BRL", "priceMicros": "4900000" }
  }
}
```

> [!IMPORTANT]
> Always pass `autoConvertMissingPrices=False` in API requests. If set to `True`, Google Play will wipe out custom Purchasing Power Parity (PPP) numbers for any unspecified regions and replace them with raw exchange rates.

```bash

```

### 2. Export Your Pricing Matrix
1. Open **PlayPrice Engine** (`index.html`) in your browser.
2. Select your active product (e.g. `Gold 3`).
3. Click the **Export CSV** button in the header (or **Export Data** for JSON backup).

## 5. Alternative: Node.js Implementation

If your build pipeline is Node.js/TypeScript:

```bash
npm install googleapis
```

```javascript
const { google } = require('googleapis');
const fs = require('fs');

async function syncPricesToPlayConsole() {
  const auth = new google.auth.GoogleAuth({
    keyFile: 'service-account.json',
    scopes: ['https://www.googleapis.com/auth/androidpublisher']
  });

  const play = google.androidpublisher({ version: 'v3', auth });

  const packageName = 'com.mygame.shop';
  const sku = 'com.mygame.shop.gold-3';

  // Read prices from PlayPrice CSV/JSON
  const pricesPayload = {
    US: { currency: 'USD', priceMicros: '1490000' },
    IN: { currency: 'INR', priceMicros: '39000000' },
    DZ: { currency: 'DZD', priceMicros: '64580000' },
    AL: { currency: 'USD', priceMicros: '490000' }
  };

  const response = await play.inappproducts.patch({
    packageName: packageName,
    sku: sku,
    autoConvertMissingPrices: false,
    requestBody: {
      packageName: packageName,
      sku: sku,
      prices: pricesPayload
    }
  });

  console.log('Successfully updated SKU:', response.data.sku, response.data.status);
}

syncPricesToPlayConsole().catch(console.error);
```

## 6. Real-World Propagation & Verification

1. **Where to see updates in Play Console:**
   * Go to **Monetize > Products > In-app products**.
   * Click on your SKU $\rightarrow$ click **Update prices** (or scroll to the pricing table).
   * You will see the individual country overrides matching the values submitted by the API.
2. **Review & Approval:**
   * In-app product price changes do **not** trigger a full app review or binary release cycle.
   * They go live automatically.
3. **Propagation Latency:**
   * Play Store client apps cache pricing metadata. Expect live updates to take **15 minutes to 2 hours** to reach global users on their mobile devices.
